# Rameev C Compiler (Транслятор Rameev -> C)

Этот модуль транслирует программы на языке **Rameev** в чистый, портируемый код на **C (C99)** и компилирует их в нативный исполняемый файл `.exe`.

## Архитектура

```
Исходный код Rameev (.rmv)
           │
           ▼
 Лексер и Парсер (AST)
           │
           ▼
 CTranspiler (rameev_c/transpiler.py)
           │
           ▼
 Чистый Си-код (.c) + рантайм-библиотека rameev_runtime.h
           │
           ▼ (GCC / Clang / TCC)
 Готовый сверхбыстрый бинарник (.exe)
```

## Структура папки `rameev_c/`

- **`rameev_runtime.h`** — компактная заголовочная библиотека на C, реализующая:
  - Динамическую типизацию `RValue` (int, double, string, boolean, list, none);
  - Динамические списки и строки;
  - Встроенные функции `print()`, `len()`, `gud()`, `int()`, `dbl()`, `str()`, `add()`, `remove()`;
  - Все операторы арифметики, логики и сравнения;
  - Конкатенацию и умножение строк (`' ' * a`).
- **`transpiler.py`** — модуль трансляции дерева AST в читаемый C-код.
- **`rameew.py`** — CLI-утилита компиляции и запуска:
  - Автоматически находит установленный в системе компилятор (GCC, Clang, TCC или MSVC `cl`);
  - Генерирует `.c` файл, компилирует его в `.exe` и сразу запускает.
- **`rameew.cmd`** — скрипт для быстрого запуска из командной строки Windows.
- **`test_features.rmv`** — тестовый файл, проверяющий весь функционал языка.

## Использование

### 1. Трансляция и запуск (если установлен C-компилятор):
```bash
python rameev_c/rameew.py main.rmv
```
или через cmd-скрипт:
```cmd
rameev_c\rameew main.rmv
```

### 2. Только генерация Си-кода (без компиляции):
```bash
python rameev_c/rameew.py main.rmv --c-only
```
Рядом с вашим файлом появится файл с расширением `.c`.

### 3. Компиляция вручную через GCC:
```bash
gcc -O2 -I rameev_c main.c -o main.exe
./main.exe
```

## Как установить C-компилятор на Windows (если ещё не установлен)

- **Вариант 1 (MinGW через winget / choco):**
  ```powershell
  winget install MSYS2.MSYS2
  # или
  choco install mingw
  ```
- **Вариант 2 (Tiny C Compiler - TCC):**
  Самый маленький и быстрый компилятор (весит меньше 2 МБ, компилирует за 0.01 сек).
  Достаточно распаковать его и добавить в `PATH`.
