# 🚀 Язык программирования Rameev

![Status](https://img.shields.io/badge/status-in%20development-orange)
![Made with](https://img.shields.io/badge/made%20with-Python-blue)
![Transpiles to](https://img.shields.io/badge/transpiles%20to-C99-lightgrey)

**Rameev** — это современный учебный язык программирования, названный в честь **Башира Искандаровича Рамеева** (1918–1994), выдающегося советского инженера и изобретателя, одного из основоположников отечественной вычислительной техники и главного конструктора первых советских ЭВМ (серии «Стрела» и «Урал»).

---

## 🎯 Цель языка

Язык **Rameev** создается не как узкоспециализированный инструмент, а как **мостик (bridge language)** между высокоуровневым языком **Python** и классическими C-подобными языками (**C++**, **Java**, а также **Pascal**).

* **От Python** язык унаследовал простоту восприятия, динамическую типизацию, удобные функции ввода-вывода и мощные списковые структуры.
* **От C-подобных языков** — явную блочную структуру с фигурными скобками `{ }`, круглые скобки в условиях и циклах, знакомый синтаксис комментариев `//` и C-стиль операторов.

Благодаря этому учащиеся могут легко освоить алгоритмическое мышление без перегруженного синтаксиса, а затем бесшовно перейти к изучению C++, C# или Java.

## ⚡ Быстрый старт (Quick Start)

### Запуск программы

Файлы с кодом на языке Rameev имеют расширение `.rmv`. 

Для запуска скрипта выполните в консоли:

```bash
rameev your_code.rmv
```

> **Примечание:** если утилита командной строки ещё не добавлена в системный `PATH`, запустить программу можно напрямую через интерпретатор Python:
> ```bash
> python main.py your_code.rmv
> ```

## 💡 Синтаксис и возможности языка

### 1. Переменные и динамическая типизация

В Rameev переменные не требуют жесткого объявления типа при создании. Переменная может свободно изменять свой тип прямо во время выполнения программы:

```rameev
a = 1                             // Переменная типа integer (целое число)
b = 1.2                           // Переменная типа double (число с плавающей точкой)
c = 'hello'                       // Переменная типа text / string
d = '123'                         // Текстовая строка из цифр
e = True                          // Логический тип (boolean): истина
e1 = False                        // Логический тип (boolean): ложь
f = [1, 2, 3]                     // Список (list) с числовыми значениями
f1 = ['apple', 'banana', 'melon'] // Список (list) со строковыми значениями
g = none                          // Пустое значение (аналог None в Python или null в C++)

// Демонстрация динамической типизации:
a = 1                             // Изначально a — это целое число
a = "hello"                       // Теперь переменная a стала строкой
```

📌 **Однострочные комментарии:** начинаются с двух символов слеш — `//`.

---

### 2. Типы данных

| Тип в Rameev | Описание | Пример значения |
| :--- | :--- | :--- |
| `integer` | Целые числа | `42`, `-7`, `0` |
| `double` | Вещественные числа (числа с плавающей точкой) | `3.14`, `0.5`, `-12.0` |
| `string` / `text` | Текстовые строки (в одинарных или двойных кавычках) | `'Привет'`, `"Rameev"` |
| `boolean` | Логический тип данных | `True`, `False` |
| `list` | Упорядоченный список элементов | `[1, 2, 3]`, `['a', 'b']` |
| `none` | Специальный тип, обозначающий отсутствие значения | `none` |

---

### 3. Преобразование типов (Type Casting)

Rameev поддерживает встроенные функции для явного приведения типов:

| Функция | Назначение | Особенности и ограничения |
| :--- | :--- | :--- |
| `int(value)` | Преобразует значение в целое число | Если строка содержит нечисловой текст, будет вызвана ошибка |
| `dbl(value)` | Преобразует значение в дробное число (`double`) | Если строка не может быть приведена к числу, возникнет ошибка |
| `str(value)` | Преобразует значение переменной любого типа в текст | Корректно форматирует числа, булевы значения, списки и `none` |

---

### 4. Работа со списками (List)

Списки в Rameev поддерживают индексацию, проверку длины, добавление и удаление элементов.

#### Индексация
Индексы начинаются с нуля (`0`):
```rameev
f = [10, 20, 30]
print(f[0]) // Выведет 10
```

> ⚠️ **Важно:** при обращении к несуществующему индексу (например, `f[100]` или отрицательный индекс `f[-1]`), программа завершится с ошибкой выхода за пределы диапазона списка.

#### Определение длины: `len()`
```rameev
f = [1, 2, 3]
print(len(f)) // Выведет 3
```

#### Добавление элемента: `add()`
Функция `add(list, value)` принимает имя списка и добавляемое значение:
```rameev
f = [1, 2, 3]
a = int(gud('Введите число: '))
add(f, a)
print(f) // Выведет: [1, 2, 3, a]
```

#### Удаление элемента: `remove()`
Функция `remove(list, index)` удаляет элемент по указанному **индексу**:
```rameev
f = [10, 20, 30]
remove(f, 1) // Удаляем элемент с индексом 1 (значение 20)
print(f)     // Выведет: [10, 30]
```

> 💡 **Правило строгой типизации содержимого списков:**
> * В **числовой список** нельзя добавлять текст (вызовет ошибку).
> * В **список строк** можно добавлять числа — они автоматически преобразуются в текстовый формат.

### 5. Ввод и вывод данных

#### Вывод: `print()`
Функция `print()` принимает произвольное количество аргументов через запятую и выводит их через пробел:
```rameev
print("Результат:", 42, True)
print() // Вызов без аргументов выводит пустую строку
```

#### Ввод: `gud()`
Функция `gud()` (**Get User Data**) получает ввод от пользователя из консоли:
* Может принимать опциональный аргумент-подсказку: `gud("Введите имя: ")`.
* Может вызываться без аргументов: `gud()`.
* Всегда возвращает полученные данные в виде строки (`string`). Для математических расчетов используйте `int()` или `dbl()`.

### 6. Арифметика и операторы присваивания

#### Арифметические операции
| Знак | Операция | Пример |
| :---: | :--- | :--- |
| `+` | Сложение чисел / конкатенация строк | `5 + 2` (вернет `7`), `'a' + 'b'` (вернет `'ab'`) |
| `-` | Вычитание | `10 - 4` (вернет `6`) |
| `*` | Умножение чисел / повторение строки | `3 * 4` (вернет `12`), `'* ' * 3` (вернет `'* * * '`) |
| `/` | Деление (с проверкой деления на 0) | `10 / 2` (вернет `5.0`) |

#### Сокращенные операторы присваивания
```rameev
i += 1  // Эквивалентно: i = i + 1
i -= 1  // Эквивалентно: i = i - 1
i *= 2  // Эквивалентно: i = i * 2
i /= 2  // Эквивалентно: i = i / 2
```

### 7. Операторы сравнения и логика

#### Операторы сравнения
| Оператор | Значение | Пример |
| :---: | :--- | :--- |
| `<` | Меньше | `a < 10` |
| `>` | Больше | `a > 0` |
| `<=` | Меньше или равно | `a <= 5` |
| `>=` | Больше или равно | `a >= 1` |
| `==` | Равно | `name == 'admin'` |
| `!=` | Не равно | `status != False` |

#### Логические операторы
| Оператор | Пояснение | Пример использования |
| :---: | :--- | :--- |
| `and` | Логическое «И» | `a > 0 and a < 10` |
| `or` | Логическое «ИЛИ» | `x == 1 or y == 2` |
| `not` | Логическое отрицание «НЕ» | `not is_active` |

---

### 8. Управляющие конструкции

#### Условные операторы: `if`, `else if`, `else`
```rameev
a = int(gud("Введите число: "))

if (a > 0 and a < 4) {
    print("Ваше число находится в диапазоне от 1 до 3")
} else if (a == 4) {
    print("Вы ввели граничное число 4")
} else {
    print("Ваше число вне диапазона от 1 до 4")
}
```

#### Цикл: `while`
```rameev
count = 3
while (count > 0) {
    print("Отсчет:", count)
    count -= 1
}
print("Старт!")
```

### 9. Сводная таблица функций и ключевых слов

| Конструкция | Тип | Назначение |
| :--- | :--- | :--- |
| `print(...)` | Функция | Вывод значений в стандартный поток вывода |
| `gud([msg])` | Функция | Получение данных от пользователя (Get User Data) |
| `len(coll)` | Функция | Получение длины списка или строки |
| `add(lst, val)` | Функция | Добавление элемента в конец списка |
| `remove(lst, idx)`| Функция | Удаление элемента из списка по индексу |
| `int(v)` / `dbl(v)` / `str(v)` | Функции | Явное приведение типов данных |
| `if () {} else if () {} else {}` | Конструкция | Условные переходы |
| `while () {}` | Цикл | Цикл с предусловием |
| `break` / `continue` | Ключевые слова | Управление ходом цикла |

## 📂 Примеры программ (`examples/`)

В репозитории подготовлена коллекция демонстрационных программ:

1. **`examples/hello_world.rmv`** — базовый синтаксис и вывод текста в консоль.
2. **`examples/calculator.rmv`** — пользовательский ввод через `gud()`, конвертация типов и вычисления.
3. **`examples/list_ops.rmv`** — полный цикл работы со списками (`add`, `remove`, `len`, срезы по индексам).
4. **`examples/fizzbuzz.rmv`** — классическая алгоритмическая задача с циклом `while()`, ветвлением и логическими операторами.
5. **`examples/password_check.rmv`** — интерактивная проверка доступа со строковым сравнением `==` и `!=`.
6. **`examples/dynamic_typing.rmv`** — демонстрация смены типов переменной во время выполнения скрипта.
